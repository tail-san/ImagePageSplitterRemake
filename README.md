**[English]**
- **Automatic Page Splitting**: Automatically detects and splits double-page spreads into single pages.
- **Windows 11 / 10 (64-bit) Support**: Fully optimized for modern 64-bit Windows environments.
- **WebP Batch Conversion**: Bulk convert images to WebP format to save storage space.
- **Archive Extractor**: Automatically extracts and processes zip and other archive formats directly.
- **Auto-Trimming & Deskew**: Corrects tilted images and removes unnecessary margins.
